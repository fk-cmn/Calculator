# Experiment Report

## 一、实验目的

- 了解 Windows 应用程序的基础知识、窗口消息机制与控件交互。
- 熟悉 Visual Studio 的 MFC 基础类库，掌握对话框（Dialog-based）应用的创建与事件处理。
- 学会使用控件 ID、消息映射（Message Map）和数据交换（DDX）机制完成简单界面逻辑。
- 通过实现一个支持表达式优先级的计算器，掌握输入处理、表达式解析（Shunting-yard）、逆波兰求值以及异常处理。

## 二、实验内容及要求

实现一个简单的计算器系统，功能包括：
- 支持中缀表达式输入并按数学优先级计算（+ - * / 和括号）。
- 支持小数、负数与三角函数 sin/cos/tan（输入以度为单位）。
- 提供清除、退格功能以及输入显示。
- 对除零、语法错误、三角函数定义域错误等进行提示处理。

## 三、测试情况（截图在 docs/screenshots）

- 测试 1：输入 `12.3+4.7` -> `=` -> 结果 `17`（截图: add.png）
- 测试 2：输入 `2+3*4` -> `=` -> 结果 `14`（乘法优先，截图: precedence.png）
- 测试 3：输入 `10/0` -> `=` -> 弹出错误“数学错误：除以零”（截图: divzero.png）
- 测试 4：输入 `30sin` 或 `sin(30)` -> `=` -> 结果 `0.5`（截图: sin.png）

（注：截图为预生成文件放在 docs/screenshots，打开对话框查看示例）

## 四、实验总结

本次实验实现了一个基于 MFC 对话框的计算器，采用 Shunting-yard 算法将中缀表达式转换为逆波兰表达式（RPN），再对 RPN 进行求值，从而支持运算优先级与括号。处理了除零、函数定义域与基本语法错误。后续可改进点：支持更丰富的函数库、表达式历史、键盘快捷键，以及更完善的单元测试。
